# ドイツ留学ラボ｜第1段階 TOPページ

ZIPを展開し、`index.html` をブラウザで開いてください。HTML・CSS・JavaScript・画像を同じフォルダ構成のまま配置すれば、サーバーへのアップロードでも利用できます。npm・ビルド・外部ライブラリは不要です。TOPのみの制作で、基本情報・コラム・大学情報の別ページは含みません。

## デザインの基準

`wkkanekin/hungary-study` のmainブランチのindex.html、style.css、script.js、images.json、students.json、config.jsonを読み取り、ヒーロー画像とシリーズロゴも確認しました。クリーム系背景、紺の見出し、青のグラデーションボタン、18〜20pxの角丸、カードの影、追従目次、現役生カードのデザインを引き継いでいます。今回の更新では紹介の重複をなくし、一人1枚のカードへ統合しました。

ヒーローは画像内の文字に頼らずHTMLでドイツ版のタイトルを表示。共通マーク・紺／青／金の配色を維持しています。ハンガリーの建物写真・制度・予約先・記事・地図は転用していません。料金はユーザーの追加指示に基づき、ハンガリー版と同じZoom40分25 USD、LINE10日間5,000円／30日間15,000円を表示しています。フォント指定はハンガリー版のNoto Sans JP／system-uiを継承し、ヒーローでは既存画像の雰囲気に合わせ日本語の明朝系システムフォントを使用。外部フォントの読み込みはありません。

## 人物情報の扱い

- 3名を「共同運営者・現役学生」として紹介し、大学・専攻・入学年・語学・出願経験・相談テーマを添付資料から整理しました。
- 山田さんの学年・奨学金なしの記載は、資料内の掲載希望に合わせ省略。資料間で解釈が分かれる「最終学歴：修士」は使わず、明確に確認できる中央大学卒業の経歴を記載しました。
- 河北さんの「2学期生」は資料記載時点から変わる可能性があるため省略。将来セメスターの授業言語については「資料記載時点」と明記しています。
- 朝日さんの大学・専攻は現役生登録資料の記載を優先しています。学年は記載していません。
- メッセージは添付資料を要約しています。個人メール・Zoom ID／パスコード・口座情報は公開ファイルに含めていません。

## 今後の追加

1. `#future-content` の各準備中表示を、実際のページ公開後にリンクへ変更します。今はダミーリンクを入れていません。
2. 基本情報の追加時は既存のbasicCard、コラムはcolumnGridなど、共通CSSのクラスを基準に追加できます。追加ページに必要な専用CSS・JSは別途用意してください。
3. メンバー追加時は `#students .memberGrid` 内にstudentCardを追加します。「共同運営者」のoperatorBadgeは共同運営者だけに付けてください。大学・専攻・自己紹介・相談内容は常時表示し、出願情報・経歴と留学メッセージはdetailsで開閉できます。
4. サービス・料金の案内を追加しました。予約方法・相談窓口は未設定のため、受付開始の案内のみ掲載し、人物カードに相談するボタンは置いていません。決済・予約先はドイツ版の正式なものが確定してから追加してください。
5. 公開先が決まったらcanonicalとog:urlを設定できます。未確定ドメインやハンガリーのOGP画像は設定していません。

GitHubへのcommit・push・PR、既存ファイルへの変更、サイト公開は行っていません。
