# 詳細ガイドへの案内ルール

実装元は `seo-navigation.css` の `.seo-guide-link`。個別ページでサイズや色を上書きしない。

- 用途：説明を読んだ後に詳細ガイドへ進む独立したリンク、関連記事のガイド案内。
- 本文中の出典・公式情報・大学一覧・目次・コラムへのリンクには適用しない。
- フォント：本文から継承。16px、太さ700、行間1.6。スマホでも同じ。
- 色：青 #1d4ed8、白文字。ホバーは #173a8f。
- 余白：上下12px・左右16px。角丸12px、最低高さ48px。
- 複数案内の間隔：12px。画面幅640px以下で横幅100%。長い文字は折り返す。
- 右端の矢印と、遷移先・読む内容が分かるリンク文言を使う。
- キーボード操作では3pxのフォーカス枠を表示する。
- 生成HTMLの変更は生成スクリプトにも反映する。

検証：リンク先の存在、生成スクリプトの整合性、計算済みスタイル、はみ出し、公開ページへの反映を確認する。
